# Pulse Central

A worldwide briefing on AI. It reads 200+ public sources, keeps only AI stories, sorts them into
six streams and links every card to the original.

**Live site:** https://projectaipulse.com/ · **Version 2** (3 October 2026)

## Streams

| Stream | What's in it | Updated |
|---|---|---|
| **Releases** | New models, products and open-source launches | Labs every 30 min; the rest every 6 h |
| **Industry** | Company news, deals, AI incidents, studies, opinion | Every 6 h |
| **Research** | Papers only | Every 6 h |
| **Regulation tracker** | AI proposals, laws, bodies and standards, by country | Every 6 h |
| **Policy** | What governments, courts and politicians do about AI | Every 6 h |
| **Infra** | AI's data centres and their power, water, land and emissions | Every 6 h |

## Features

- **Front page:** the latest stories, Today in AI, what people are discussing, the week's story, word and meme, and the topics most in the news.
- **Six streams**, each with its own page, sub-pages, filters and search back to 2023.
- **One card per event**, in English (other languages translated offline).
- **Pulse Daily and Pulse Weekly:** an email with the streams and topics you pick, a company of the day and of the week, a two-minute audio digest and a page of the day's stories for each kind of reader. [See a sample](https://projectaipulse.com/daily/sample.html).
- **Weekly dossier:** your own questions, answered with the week's stories.
- **[AI laws by country](https://projectaipulse.com/tracker/):** laws, bills, AI bodies, [standards](https://projectaipulse.com/standards/) and [sector-specific rules](https://projectaipulse.com/tracker/sector-specific/), each with its stage.
- **[Topics](https://projectaipulse.com/topics/):** storylines followed over time, news and laws on one timeline, each opening with The story so far.
- **[The month in AI](https://projectaipulse.com/monthly/):** a booklet and a page of insights for every month since January 2026.
- **[Glossary](https://projectaipulse.com/glossary/):** AI words in plain English, each with its newest story.
- **Saved stories** (kept in your browser only), **dark mode** and **RSS**: one feed per stream, or [all at once](https://projectaipulse.com/feeds/all.opml).

## How we keep it legal

1. **robots.txt must allow us**, checked before every request (RFC 9309). github.com pages are never read, only GitHub's API.
2. **Terms:** sites are read only if their terms don't forbid robots or limit use to personal use. For AI labs' own blogs, and sites whose terms can't be opened, robots.txt decides.
3. **No workarounds:** nothing behind a login, bot check or paywall.
4. **Only what's needed:** headline, short description, date and link.
5. **Credit and non-commercial use**, as the licences ask.
6. **No tracking of readers:** visits are counted anonymously (GoatCounter: no cookie, IP address or ID kept); see the [privacy page](https://projectaipulse.com/privacy.html).

Every source's robots.txt and terms were audited on 7 October 2026; the evidence is in `aipulse/terms.py` and
`python -m aipulse audit` checks them again. Questions: projectaipulse@gmail.com.

## How it runs

Python, almost all standard library, and one SQLite database; no server and no paid API. Every 6 hours a GitHub
Actions run collects, sorts and builds the site, then publishes plain pages to GitHub Pages. The email is sent by
`.github/workflows/digest.yml` and sign-ups go to a Google Apps Script web app (`apps-script/Code.gs`). The domain
(about $11 a year) is the only cost.

| Where | What's there |
|---|---|
| `aipulse/` | The code: `python -m aipulse --help` lists every job; `config.py` lists every setting; one module per feature page |
| `templates/` | The pages' shell, fonts, icons and pictures |
| `tests/` | The tests and their sample feeds |
| `.github/workflows/` | Collect and publish, the email, and the notes on draft branches |
| `data/seed.db.gz` | The database a run starts from when there is no saved copy |

## Run it

```bash
pip install -r requirements-dev.txt   # pinned packages, with test and lint tools
git config core.hooksPath hooks       # once: lint and tests before each commit that changes Python
python -m aipulse collect             # fetch every source into aipulse.db
python -m aipulse serve               # http://127.0.0.1:8000
python -m aipulse audit               # check every source's robots.txt and terms again
python -m pytest -n auto              # tests, run locally (never on Actions)
python -m ruff check .                # lint
```
